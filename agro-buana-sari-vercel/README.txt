PT AGRO BUANA SARI — VERCEL STATIC WEBSITE

Project ini sudah disiapkan sebagai website statis (HTML, CSS, JavaScript) agar dapat di-deploy langsung ke Vercel.

CARA DEPLOY KE VERCEL
1. Ekstrak file ZIP ini.
2. Buka https://vercel.com/ lalu login.
3. Pilih Add New → Project.
4. Import repository GitHub yang berisi seluruh isi folder ini, atau gunakan Vercel CLI dari folder project.
5. Framework Preset: Other.
6. Build Command: kosongkan / None.
7. Output Directory: . (root project).
8. Klik Deploy.

CATATAN PENTING
- Versi ini adalah website company profile statis. Tidak membutuhkan PHP atau database untuk tampil di Vercel.
- Fitur PHP lama seperti login, admin dashboard, stok produk dinamis, unggah CV, dan pengelolaan artikel tidak ikut berjalan pada versi statis ini. Untuk fitur tersebut dibutuhkan backend/API dan database yang di-host terpisah atau migrasi ke layanan backend.
- Informasi target 1.000 hektare, 5.000 ton, dan IPO Q3 2027 ditampilkan mengikuti informasi yang diberikan sebagai materi awal. Pastikan kembali dan sesuaikan sebelum website dipublikasikan.
- Ganti alamat email contoh di bagian Hubungi Kami dengan kontak resmi perusahaan.
- Semua gambar yang tersedia dari folder assets project asal tetap disertakan.
